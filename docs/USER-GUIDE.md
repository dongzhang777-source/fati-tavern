# FATI Tavern 用户使用说明

## 一句话介绍

拖一张角色卡进来，和 TA 聊天。你的 Key 和聊天记录不离开你的设备。

## 快速开始（3 分钟）

### 1. 打开应用

访问 [https://fati-tavern.vercel.app](https://fati-tavern.vercel.app)（手机/电脑浏览器均可，支持"添加到主屏幕"作为 PWA 使用）。

### 2. 配置 API 端点

点击右上角 ⚙ 按钮打开设置面板：

- **选择预设**：DeepSeek / Kimi / OpenAI / LM Studio / Ollama / 自定义
- **填入 API Key**：从对应平台获取（如 DeepSeek 的 Key 几块钱能用很久）
- **选择模型**：点击「测试连接 & 拉取模型」按钮，成功后会显示可用模型下拉列表
- 点击空白处关闭设置

> 你的 API Key 只存在浏览器 localStorage 中，不会上传到任何服务器。

### 3. 导入角色卡

两种方式：

- **拖拽**：把角色卡文件（.png 或 .json）直接拖到页面任意位置
- **按钮**：点击「+ 导入角色卡」选择文件

支持的格式：
- SillyTavern PNG 角色卡（v3 tEXt chunk）
- JSON 角色卡（v1 / v2 格式）
- 世界书 JSON（自动关联到角色）

### 4. 开始聊天

在角色库中点击任意角色卡片 → 进入聊天界面 → 输入消息 → 发送。

## 功能说明

### 角色库

- 卡片网格展示，显示头像、名称、描述、标签
- PNG 角色卡自动提取头像（128px 居中裁切）
- 悬停显示删除按钮

### 多会话

- 每个角色支持多个独立对话
- 聊天界面点击 ☰ 打开会话侧边栏
- 支持新建、切换、删除会话
- **双击会话标题**可重命名
- 会话标题自动截取第一条消息的前 20 个字

### 聊天

- 流式输出（逐字显示）
- 随时点击「停止」中断生成
- 消息带时间戳
- 自动滚动到最新消息
- 点击 🗑 清空当前对话

### 数据持久化

- 角色卡和聊天记录存储在浏览器 IndexedDB 中
- 关闭页面/重启浏览器后数据不丢失
- 清除浏览器数据会删除所有本地数据

## 隐私说明

| 数据 | 存储位置 | 是否上传 |
|------|----------|----------|
| API Key | localStorage | 否 |
| 角色卡 | IndexedDB | 否 |
| 聊天记录 | IndexedDB | 否 |
| 聊天请求 | 直接发往你配置的 API 端点 | 仅发往你选择的服务商 |

本应用是纯前端 PWA，没有自己的后端服务器。所有数据只存在于你的浏览器中。

## 常见问题

**Q: 发送消息报错 HTTP 401？**
A: API Key 无效或过期，请在设置中检查。

**Q: 发送消息报错 HTTP 404？**
A: 模型名称不正确。点击「测试连接 & 拉取模型」获取可用模型列表。

**Q: 导入 PNG 没有反应？**
A: v0.2.0 起导入失败会弹出具体原因提示。确认是 SillyTavern 格式的角色卡 PNG（内含 chara/ccv3 数据块），gzip 压缩卡已支持。普通图片不支持。

**Q: 选了 LM Studio / Ollama 预设但连不上？**
A: 本地端点需要开启 CORS 才能被网页访问：
- **LM Studio**：在 Server 设置中打开「Enable CORS」再启动服务；
- **Ollama**：启动前设置环境变量 `OLLAMA_ORIGINS=*`（macOS/Linux：`launchctl setenv OLLAMA_ORIGINS "*"` 或 `OLLAMA_ORIGINS=* ollama serve`）。

配置完成后可用设置面板的「发送测试消息」验证聊天链路是否真正可用。

**Q: 换手机/电脑后数据还在吗？**
A: 不在。数据只存本地浏览器，不支持云同步。角色卡文件可以重新拖入导入。

**Q: 支持哪些 AI 服务？**
A: 任何兼容 OpenAI API 格式的服务（/v1/chat/completions），包括但不限于 DeepSeek、Kimi、OpenAI、LM Studio、Ollama、vLLM、LocalAI 等。
