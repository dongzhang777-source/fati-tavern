# P2P 群聊使用指南

## 1. 是什么

FATI Tavern（肥猫酒馆）支持以手机或浏览器加入桌面端 FATI 创建的 P2P 房间。在房间里可以：

- **群聊**：与同房间的其他浏览器参与者实时聊天
- **借算力**：借用桌面端 FATI 的本地算力进行流式 AI 推理

整个过程无需注册、无需服务器账号——只需一张邀请票据。

## 2. 前置条件

| 条件 | 说明 |
|------|------|
| 桌面端运行 FATI | 需要桌面 FATI 同时启动 **relay**（中继）和 **server**（算力端） |
| 浏览器要求 | Safari ≥ 17、Chrome ≥ 113（需支持 Web Crypto Ed25519） |
| 网络环境 | 手机与桌面在同一 Wi-Fi；**或** relay 开放公网 WSS 地址 |

> **注意**：如果桌面端只启动了 relay 而未启动 server，房间内将没有算力端，无法使用「借算力」功能。

## 3. 加入房间步骤

1. **桌面端启动 relay**  
   该脚本位于 **fati 桌面端仓库**（仓内路径 `scripts/start-relay.sh`），**不在本 Web 仓 fati-tavern 内**。在桌面端仓库运行它，终端会打印一行：  
   ```
   INVITE_TOKEN: eyJ...签名...
   ```  
   复制这串票据（INVITE_TOKEN）。

2. **手机打开酒馆**  
   在手机浏览器访问 FATI Tavern 地址（PWA）。

3. **进入 Gallery 的 P2P 面板**  
   在画廊页面找到 **👥 P2P 群聊** 设置卡片，点击进入。

4. **粘贴票据**  
   将桌面端复制的 INVITE_TOKEN 粘贴到输入框。

5. **加入房间**  
   点击「加入」按钮。酒馆会验证票据、连接 relay、完成密钥交换。

6. **进入群聊**  
   加入成功后，切换到聊天页面的 **群聊 Tab**，即可看到房间消息并开始发言。

## 4. 借算力

进入有算力端（桌面 FATI server）的房间后：

1. 点击聊天界面的 **🖥 借算力** 按钮
2. 输入你想让 AI 回复的 prompt
3. 桌面端会进行流式推理，结果逐字返回到聊天中

**关于取消**：点击「取消」只会停止你本机的显示接收，**不会**中断桌面端的推理计算（协议层面没有取消消息）。

> 如果房间内没有算力端（比如自建房），🖥 按钮不会出现。

## 5. 加密说明

| 场景 | 加密状态 | 说明 |
|------|----------|------|
| 有桌面算力端的房间 | 🔒 端到端加密 | 桌面 server 分发 AES-256-GCM 群密钥，所有 `chat` 消息加密传输（群密钥帧带算力端 Ed25519 签名，客户端用票据内公钥验签后采信） |
| 自建房（无算力端） | ⚠️ 明文 | 没有 server 分发群密钥，消息经 relay 明文转发 |

- `compute_request` / `compute_result`（借算力请求和结果）**始终明文**传输
- 端到端加密房间的密钥交换使用 ECDH P-256，消息签名使用 Ed25519
- **保密性边界（2026-09-11 起）**：群密钥帧带算力端 Ed25519 签名，客户端用**票据内公钥**验签且无签名一律拒收，因此中继服务器**替换密钥的伪造帧会被拒绝**——但它仍可丢帧/断连（可拒绝服务，不可解密）。
  - 前提：票据本身须经可信渠道交到你手里（票据由算力端自签，无外部锚点）
  - 兼容性：本版本已拒收未带签名的旧算力端（需桌面端同步升级）

## 6. 常见问题

### https 页面连不上 `ws://` 地址？

浏览器安全策略禁止从 HTTPS 页面发起不安全的 `ws://` WebSocket 连接（`ws://localhost` 除外）。

**解决办法**：
- 使用局域网开发地址：手机访问 `http://192.168.x.x:5173`（`npm run dev -- --host` 启动），HTTP 页面可以连 `ws://`
- 或者让 relay 开启 WSS（`wss://`）并使用受信证书

### 断线后重连失败？

网络切换（Wi-Fi → 蜂窝）或长时间后台后，WebSocket 可能断开。酒馆会自动尝试重连，如果自动重连失败：
- 手动点击聊天界面的「重连」按钮
- 或退出房间后重新粘贴票据加入

### 浏览器提示不支持？

如果浏览器不支持 Web Crypto Ed25519（iOS ≤ 16、旧版 Firefox 等），加入房间时会提示「浏览器不支持」。请升级到 Safari 17+ 或 Chrome 113+。

## 7. 隐私

- **票据与密钥**：仅存储在你本机的 `localStorage`，不会上传到任何服务器
- **聊天记录**：仅在内存中存在，**不写入磁盘**——关闭页面即丢失，无任何持久化
- **无服务器存储**：中继服务器（relay）只负责实时转发消息，不存储任何历史数据
- **端到端加密房间**中，relay 只能看到密文，无法解读聊天内容（群密钥经算力端 Ed25519 签名 + 端侧验签，替换公钥的伪造帧会被拒绝；relay 仍可拒绝服务）
